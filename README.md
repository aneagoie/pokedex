# pokedex

A small project for converting the images in the Pokedex folder to PNG files.

## Convert images

From the repository root, run:

```bash
python pokedex/JPGtoPNGconverter2.py pokedex/Pokedex pokedex/new
```

The first argument is the input image folder. The second argument is the output
folder. The output folder is created automatically when it does not exist.

Only JPG, JPEG, and PNG files are processed; other files in the input folder
are skipped.

*Visit https://zerotomastery.io/ for more.*
